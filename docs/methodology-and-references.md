# Methodology and Reference Notes

## Why these sources?

### NIST SP 800-115
NIST SP 800-115 provides a foundation for planning technical security assessments, conducting tests, analysing results, and developing mitigation strategies. It supports this project's emphasis on pre-test planning, agreed scope, execution records, and reporting. It is guidance, not a claim that this student project is NIST-certified.

URL: https://csrc.nist.gov/pubs/sp/800/115/final

### OWASP Web Security Testing Guide (WSTG)
The OWASP WSTG organises web security testing into categories and includes testing and reporting guidance. The test register in this project is a small, selected set inspired by general web testing practice; it is not a reproduction of the full guide and does not claim complete WSTG coverage.

Stable guide: https://owasp.org/www-project-web-security-testing-guide/stable/

### OWASP Juice Shop
OWASP describes Juice Shop as an intentionally insecure web application used for security training and testing tools. It can provide a controlled target when the intern runs a local instance. The public demo is not included in this project's authorised scope.

Project page: https://owasp.org/projects/juice-shop  
Developer guide: https://devguide.owasp.org/en/07-training-education/01-vulnerable-apps/01-juice-shop/

## Research method
- Reviewed the task requirement and translated it into operational controls and document outputs.
- Used public, authoritative project/documentation pages for the methodology.
- Created a compact set of candidate tests appropriate to a student-controlled demo application.
- Avoided asserting empirical findings because no application was tested.
- Kept lab instructions optional and limited to a locally controlled target.

## Reference quality and limitations
NIST and OWASP are primary sources for their respective guidance and project descriptions. The selected references do not replace application-specific documentation, legal review, or written permission from the target owner. Always record the version and date of guidance used if a formal engagement requires traceability.
