# Evidence Handling

## Rules
- Evidence must come from an approved target and actual test activity.
- Use synthetic accounts and test data.
- Redact usernames if personal, email addresses, session cookies, authorization headers, tokens, passwords, internal hostnames where sensitive, and any real user data.
- Do not place raw sensitive evidence in a public GitHub repository.
- Keep original evidence in an access-controlled location; commit only safe, redacted copies.
- Record timestamps with time zone and link evidence to test-case IDs.
- Never fabricate screenshots or test results.
