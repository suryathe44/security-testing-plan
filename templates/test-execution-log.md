# Test Execution Log

## Status definitions
- `Not Run`: no execution has occurred.
- `Run - No issue observed`: test performed and the expected secure behaviour was observed; this does not prove absence of vulnerabilities.
- `Finding observed`: evidence supports a potential weakness requiring analysis.
- `Blocked`: test could not be performed safely or within scope.
- `Retest pending`: remediation has been reported but not yet verified.
- `Retest passed`: the specific issue did not reproduce during the authorised retest.
- `Retest failed`: the issue remains reproducible during authorised retest.
